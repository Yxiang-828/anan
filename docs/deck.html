Team SyntaxError3

The origin · 起点

Not a chat window — an autonomy research program.

Eighteen research artifacts on what makes an agent more than an LLM plus a scheduler. The core law: WAKE ≠ THINK ≠ ACT — a trigger is only the opportunity to inspect; cognition is a separate decision; action is another.

WAKE→THINK→ REVALIDATE→GATE→ ACT→RECEIPT→COMMIT

Every action, seven phases — every phase writes a receipt into the store, streamed live to the judges' console. Claims are not the interface. Receipts are.

The skeleton · 骨架

IDLE → CHECKIN_SENT (07:30 greeting arms 60′)

 → SILENCE_2 → ESCALATED (daughter → son → neighbour)

  • The contact tree actually walks — per-hop idempotent receipts.
  • Every touch is a heartbeat: a med tap, a word — the net dissolves.
  • All windows are family-configured data, not code.

The voice · 声音

We don't clone a voice. We clone presence. 她听到的不是 AI, 是女儿。

  • Family picks a language first, reads a fixed 10-second script → that language's reference voice. Never reused across languages.
  • Hot-reloads instantly; an audition plays any exact line in any voice — including your own clone.
  • Consent-first · family-only · local-only.
